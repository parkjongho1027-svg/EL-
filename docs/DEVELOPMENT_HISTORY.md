# Development History

이 문서는 실제로 확인 가능한 소스 파일, 내부 APP_BUILD 값, Git 커밋 및 태그를 기준으로 작성한 개발 이력입니다.
존재가 확인되지 않은 버전 번호는 임의로 복원하지 않았습니다.

## 후반 개발 흐름

Git 커밋 기록에서 다음 변화가 확인됩니다.

- KC 기준 검토 기능의 문서·판정 로직 정리
- 공학 데이터 도구와 모듈 구조 정리
- 시뮬레이션 차트 비교 기능 추가
- 층간 운행 애니메이션 및 승강로 위치 시뮬레이션 확장
- 현재 정지층을 기준으로 한 이동 경로 처리
- 테스트, CI, Windows 빌드 및 개발 도구 구성
- MIT License 적용

## 이력 해석 원칙

이 저장소의 목적은 버전 숫자를 억지로 1부터 연속적으로 채우는 것이 아니라, 실제 남아 있는 자료를 통해 프로그램이 어떻게 발전했는지를 재현하는 것입니다.

따라서 복구되지 않은 v1~v6, v8~ 등의 소스는 존재하는 것처럼 만들지 않습니다. 추가 원본 파일이 발견되면 해당 시점의 소스와 변경점을 검증한 뒤 이 문서에 계속 추가합니다.
