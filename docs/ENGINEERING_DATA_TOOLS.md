# 공학 데이터 도구: 범위와 재현 절차

실행: `python main.py` → **S-Curve 시뮬레이션** → **기계동력 곡선** → **공학 데이터 도구**. 세 기능의 계산 코드는 UI에서 분리되어 있습니다. 이 창은 연구용 보조 도구이고 법정 인증이나 제조사 성능 검증을 대신하지 않습니다.

## 1. 설계 후보 탐색

입력: 승강행정, 속도, 정격하중, 카 질량, 로프 단위질량, 도르래 반지름, 회전자 관성, 운전 주기, 사용 가능한 전동기 정격 목록. 로프 4~12가닥과 균형률 35~55%(2.5%p 간격)의 **81개 조합**을 검토합니다. 각 조합의 빈 카/정격 적재, 상승/하강 네 조건에 `MotorDutyInput` 및 기존 운행 모델을 적용합니다. 최대 입력 피크에 임의의 설계 여유 계수 1.15를 곱해 정격 목록에서 용량을 고르고, 피크 장력은 정적 로프 근사로 표시합니다. 여유 계수는 법적 숫자가 아닙니다. 로프의 전장 질량을 등가 이동 질량으로 취급하며 저항은 100N, 구동 효율은 0.85, 가속도는 1m/s², 저크는 0.8m/s³으로 가정합니다. 이 상수와 제조사 정격이 확정되지 않으면 선정 설계로 쓰지 마세요.

15개 기준 샘플의 k-최근접 역거리 근사로 필요 피크를 예측하고, 근사 학습에 쓰지 않은 8개 조건의 평균/최대 **수치 오차**를 표시합니다. 추천 결과는 이 근사 예측으로 결정하지 않고 모든 81개 조건에 기존 물리 계산을 재실행하여 순위를 매깁니다. 이 구성은 PINN이나 신경망 학습이 아니고 성능 우위를 주장하지 않습니다. 로프 파단강도, 실제 제동기, 모터 연속·피크 토크 정격, 회생기 사양, KC 적합 여부는 계산/검증하지 않습니다. 숫자는 **검토 후보**입니다.

## 2. 진동 데이터 분석

CSV에는 `time_s,acceleration_m_s2` 또는 `time_s,vibration` 헤더를 사용하세요. `time_s`가 없으면 Hz를 직접 입력합니다. 8 MiB 이하 파일의 처음 8192샘플을 읽습니다. `time_s` 간격이 ±5% 안에 있어야 합니다. PCM WAV는 모노 또는 스테레오 8~32비트의 처음 8192프레임을 읽어 무차원 오디오 진폭으로 표시합니다. 평균을 뺀 RMS·피크·첨두율, 낮은 128개 주파수 빈 안에서 가장 큰 성분과 원본 신호 그래프를 표시합니다. 이 주파수 목록은 전체 FFT가 아니므로 높은 주파수 결함을 놓칠 수 있습니다.

같은 형식·샘플링 조건의 비교 파일을 지정하면 RMS 비율을 계산하지만 이를 결함 종류, 확률 또는 잔여 수명으로 변환하지 않습니다. 공식 CWRU 베어링 데이터의 배포 형식은 `.mat`이며 원본은 이 CSV/WAV 업로더가 직접 읽지 않습니다: [CWRU 다운로드 안내](https://engineering.case.edu/bearingdatacenter/download-data-file). NASA IMS 자료 역시 별도의 베어링 실험 자료입니다: [NASA IMS 데이터](https://data.nasa.gov/dataset/ims-bearings). 이 자료의 성능이 승강기에서 재현된다는 근거는 없습니다. 실제 진단 모델을 만들려면 출처/운전점/센서 위치/샘플링 주파수/결함 레이블, 훈련·검증 분리, 다른 설비에 대한 외부 검증이 필요합니다. 현재 94% 진단 정확도나 RUL을 표시하지 않습니다.

## 3. 도면 입력 후보 추출

PDF 앞 5쪽에서 문자 텍스트를 추출하려면 `pypdf`가 필요합니다. 스캔 PDF는 `PyMuPDF`와 **Tesseract 실행 파일**(한글 인식에는 `kor` 학습 데이터)이 추가로 필요합니다. PNG/JPG도 Tesseract를 사용합니다. 입력 문서는 12 MiB 이하로 제한합니다.

현재 지원하는 명시적 표기: 정격하중 kg, 정격속도 m/s 또는 m/min, 승강행정 m 또는 mm, 카 자중 kg, 로프 가닥 수, 선정 전동기 kW. 숫자·단위·원본 한 줄을 함께 보여주며, 사용자가 고른 값만 관련 계산창에 입력합니다. 같은 항목의 서로 다른 추출값은 한 번에 입력할 수 없습니다. OCR과 정규식은 숫자를 잘못 읽거나 다른 문맥의 값을 가져올 수 있으므로 반드시 원본을 대조해야 합니다. 자동 합격 판정이나 YOLO/LayoutLM 학습은 포함하지 않습니다.

## 4. 81개 조합 검색과 설계 데이터 내보내기

**목표 검색**은 이미 계산한 81개 표본에서 목표 피크 kW 이하이고 입력한 전동기 정격 목록에서 선정 가능한 조합을 균형률순으로 표시합니다. 연속 최적해, 슬립 방지 균형률, KC 적합 판정이 아닙니다. **전체 후보 CSV/JSON**은 선정 정격이 없는 탈락 사례까지 포함한 81개 표본의 균형률·장력·피크 토크를 저장합니다. JSON에는 입력 가정을 함께 보존합니다. CAD/CAE에서 활용하려면 하중 방향, 단위와 경계 조건을 별도로 검증해야 합니다.

**부품 명세 템플릿**은 제조사·모델·자료 출처, 로프 1가닥 kg/m, 쉬브 반지름 m, 모터 회전자 관성 kg·m², 사용 가능한 전동기 정격 kW 목록을 입력하는 JSON 빈 양식입니다. 원본 사양서로 채운 후 **부품 JSON 불러오기**에서 내용을 확인하고 적용하면 설계 후보 입력칸만 갱신됩니다. 범위·형식 검사는 하지만 출처의 진위나 실제 제품 조합 적합성을 인증하지 않으며, 기본 제조사 데이터베이스에 가상의 모델을 넣지 않습니다.

## 5. 실측 속도 겹침 및 합성 입력 예제

**실측 속도 비교** 탭의 CSV/TXT는 `time_s,speed_m_s` 머리글을 사용하고 추가 열은 무시합니다. 최대 5 MB·50,000행, 0 이상 엄격히 증가하는 시각 및 음수가 아닌 속도 크기를 요구합니다. 현재 기계동력 곡선 입력의 모델 속도를 해당 시각으로 선형 보간하여 RMSE와 최대 절대 오차를 보여주며, 비교한 전체 표본은 CSV로 저장할 수 있습니다. 시작은 0.2초 이내, 종료는 모델 시각과 5% 또는 0.5초 이내로 일치해야 합니다. 자동 시간 동기화·방향 부호 변환·센서 보정은 없습니다. 통계는 유효한 모든 행으로 계산하고, 화면에는 최대 약 1,000점만 그립니다.

**합성 CSV 생성·비교**는 현재 궤적에 고정 난수 시드, 속도/가속도 잡음, 시각 지연, 지정 거리 간격의 가상 레일 이음매 펄스와 조화파를 적용합니다. 출력 머리글은 `time_s,speed_m_s,acceleration_m_s2,source`이고 모든 행에 `SYNTHETIC_DEMO_NOT_MEASURED`가 표시됩니다. 파일을 저장하면 속도 겹침 그래프에 바로 불러오며, 진동 데이터 분석의 가속도 CSV 입력에도 사용할 수 있습니다. 이 데이터는 파일 가져오기·화면·계산의 재현 검사에만 유효합니다. 실제 현장 센서 분포, 결함 진단률, 모델의 실측 일치도를 검증하지 않습니다. 특정 상용 장비 CSV와의 호환성을 주장하지 않습니다. 현장 로그는 머리글·단위·시계 원점·측정 방향을 확인하고 사본을 공통 열로 변환하세요.

## 6. 승강로 위치 도식

**승강로 위치 (모델)** 탭은 현재 궤적 입력으로 계산한 시각을 슬라이더나 80 ms 갱신 재생으로 선택해 카와 균형추의 2D 위치를 표시합니다. 1:1 로핑 가정에서 카 위치 `x`와 균형추 위치 `행정−x`를 그리는 도식이며 창을 닫으면 재생 타이머를 중단합니다. 로핑비, 실제 승강로 치수, 과주행, 충격 하중, 간섭이나 슬립을 계산하지 않으므로 도면 또는 인증 검토에 이용하지 않습니다.

검사: `sh scripts/verify.sh` (필요 시 `PYTHON=.venv/bin/python sh scripts/verify.sh`). Linux의 자동 검사는 Windows 파일 대화상자, Tesseract 한국어 설치, 실제 제조사 문서의 OCR 정확도를 검증하지 않습니다.
