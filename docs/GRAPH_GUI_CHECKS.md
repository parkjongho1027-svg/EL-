# Windows 그래프·전동기 상세창 확인 절차

이 체크는 Tk 창을 띄울 수 없는 Linux 자동 검사와 별개입니다. Python 3.14 또는 배포 EXE에서 직접 확인한 결과를 기록하세요.

1. 전동기 용량 → **관성·가속 토크 / 열부하**: 입력창을 클릭한 채 휠을 굴려 맨 아래 `궤적 시간 간격`까지 이동합니다. 기본값의 결과가 바로 표시되는지 확인합니다. `운전 반복 주기`를 120에서 150으로 바꿔 결과의 운전율이 바뀌는지 확인합니다. Enter로 계산한 뒤 **입력 기록**에서 두 행을 체크해 다중 삭제와 기록명 변경, **결과 복사**, **입력값 삭제**, **이전 입력** 순서로 확인합니다.
2. 트랙션비: 유효한 여섯 필수 입력값을 넣고 **로프 장력 분포 그래프**를 엽니다. 원래 화면의 `H`를 바꿔 열린 그래프의 가로 눈금이 갱신되는지 확인합니다. 그래프창에서 **창 고정**을 켜고 원래 창을 클릭해도 그래프가 위에 있는지 확인합니다. **PNG 저장** 뒤 파일을 직접 엽니다.
3. 그래프창의 **그래프 저장**에서 그래프 이름과 담당자를 각각 입력합니다. 트랙션비 화면 **그래프 관리**에서 이름·담당자·저장 시각을 확인하고, 서로 다른 거리·장력 조건 두 개를 저장해 다중 선택 후 **선택 기록 불러오기**로 각각 독립된 창이 열리는지 확인합니다. 두 창의 X·Y축 눈금 범위와 PNG 저장 후 눈금이 동일한지 확인합니다. **삭제** 후 다시 열어 삭제가 유지되는지 확인합니다.
4. 교통량 분석: 먼저 유효한 계산을 실행한 후 **층별 5분 수송 그래프**를 열고 그래프창의 저장/PNG/창 고정을 확인하고, 교통량 화면 **그래프 관리**에는 수송 그래프만 표시되는지 확인합니다. 입력값을 바꾸어 교통량 계산이 끝난 뒤 수송 그래프가 갱신되는지 확인합니다. 잘못된 값으로 바꾸면 이전 수송 결과가 계속 표시되지 않는지 확인합니다.
5. S-Curve의 기계동력과 전기에너지 비교: 입력값을 바꾼 뒤 탭 안의 그래프가 자동으로 갱신되는지 확인합니다. 두 종류의 기록을 저장하고 각 탭의 **시뮬레이션 관리**에는 해당 종류만 표시되는지 확인합니다. 관리창에서 두 개를 함께 불러와 축을 비교합니다. 실측 CSV를 지정하지 않았을 때 모델 추정 문구가 유지되는지 확인합니다.

입력 조건과 창 크기, 눌렀던 버튼, 실제 결과, 오류 문구를 함께 적으면 재현에 도움이 됩니다. GUI 확인 전에는 Windows 동작이 검증됐다고 기록하지 않습니다.
