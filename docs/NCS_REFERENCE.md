# NCS 승강기 학습모듈 참고 범위

자료: [한국산업인력공단 NCS 학습모듈 검색](https://ncs.go.kr/unity/th03/ncsModuleFileSearch.do),
분류 `15-05-01-07` 승강기설치·정비, 능력단위 `06` 엘리베이터 점검.
검토한 학습 자료의 식별번호는 `LM1505010706_20v2`이며, 발행 당시의 교수·학습
자료입니다. 현재 적용 법령 또는 최신 안전기준의 원문으로 간주하지 않습니다.

해당 모듈의 학습 흐름(점검 계획, 기계실, 카, 승강로, 승강장, 피트)을 참고해
`KC 기준 검토 > 현장 관찰 기록`을 만들었습니다. 화면의 관찰 문구와 양식은
프로젝트 용도로 새로 작성했습니다. 각 위치에 관찰 상태, 기록 내용, 자료 출처를
입력할 수 있습니다. `기록 적용`은 현재 프로젝트 입력 상태에 반영하며,
`프로젝트 저장`을 누르면 여섯 화면의 입력과 함께 저장됩니다. 과거 프로젝트에는
빈 기록이 표시됩니다. `입력값 삭제`, 이전 입력 및 되돌리기도 이 기록에 적용됩니다.

이 기록은 입력자가 현장에서 확인한 내용을 보관하는 용도입니다. 상태값은
`미확인 / 관찰 기록 / 추가 확인 필요`뿐이며 합격·불합격 또는 장치 등급을
자동으로 판정하지 않습니다. KC 조항 판정, 검사 결과, 관찰 기록은 별도로
유지합니다. 실제 검사의 절차와 수치 기준은 적용되는 현행 고시·제조사
설계도서 및 검사기관 기록에서 별도로 확인해야 합니다.

NCS 학습모듈에 포함된 타인 저작권 도표·사진·도면은 이 저장소에 복제하지
않았습니다. 현재 다운로드 가능한 판본과 개정 이력은 NCS 공식 검색에서
다시 확인해야 합니다.
