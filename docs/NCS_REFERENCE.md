# NCS 승강기 분류의 설치 전 활용 범위

출처: [한국산업인력공단 NCS 학습모듈 검색](https://ncs.go.kr/unity/th03/ncsModuleFileSearch.do),
`15-05-01-07` 승강기설치·정비 분야의 `01 승강기 설치계획 수립` 능력단위.
이는 설치 전 자료 확인 작업의 분류를 참고한 것이며, 이 능력단위의 특정
학습모듈 판본이나 원문의 세부 체크리스트를 적용했다고 주장하지 않습니다.

`KC 기준 검토 > 설치 전 설계자료` 화면은 프로그램의 계산 분야에 맞춰
새로 작성한 출처 기록 도구입니다. 전동기, 로프·권상, 제동기, 교통량,
운행 시뮬레이션, 기준 검토에 사용한 도면·사양서·건물 계획자료·가정의
문서명·도면번호·버전·페이지를 남깁니다. **설치 전에도 작성할 수 있는
자료만 취급하며 실제 주행·브레이크 시험·현장 측정 결과를 요구하지 않습니다.**

`자료 기록 적용`은 현재 입력 상태에 기록을 반영하고, `프로젝트 저장`을
누르면 여섯 화면의 입력과 함께 보관됩니다. 기존 프로젝트는 빈 자료
기록으로 열립니다. 입력값 삭제, 이전 입력 및 실행 취소에 포함됩니다.
자료의 상태(`자료 없음 / 자료 있음 / 추가 자료 필요`)는 문서 확보 상황을
나타낼 뿐, 문서 내용의 진위·설계 계산의 정확성·KC 적합성 판정이 아닙니다.

설치 후 점검은 `06 엘리베이터 점검`과 별도의 작업입니다. 운행·제동
시험과 현장 관찰 사항은 이 설치 전 설계 계산 화면에 넣지 않았습니다.
KC 수치와 판정에는 적용되는 현행 기준 원문 및 제조사 설계도서의 별도
검토가 필요합니다. NCS 학습모듈의 도표·사진·도면은 복제하지 않았습니다.
